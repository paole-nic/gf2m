# gf2m

Arithmétique des corps finis GF(2^m) et algèbre linéaire associée, en Rust.

Bibliothèque écrite dans le cadre d'un travail sur la cryptographie post-quantique fondée sur les codes correcteurs d'erreurs. L'objectif est une implémentation de référence, destinée à servir  à des versions optimisées ultérieures.
